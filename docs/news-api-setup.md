# 실시간 뉴스 연동 (구글 뉴스 RSS, 완전 무료)

`newsfeed.html`의 실시간 타임라인과 `main.html`의 뉴스 리스트를 하루 3번(아침/점심/저녁) 실제 뉴스로 자동 갱신합니다.

API 키 발급도, 가입도, 카드 등록도 필요 없습니다 — 구글 뉴스가 공개로 제공하는 RSS 주소(`https://news.google.com/rss/search`)를 그냥 가져다 쓰는 방식입니다.

## 동작 방식

1. `scripts/fetch-news.js` — 구글 뉴스 RSS를 카테고리별(반도체/금리/환율/부동산/AI/경제)로 호출해 `data/news.json`을 생성합니다.
2. `.github/workflows/fetch-news.yml` — GitHub Actions가 매일 07:00 / 12:00 / 18:00(KST)에 위 스크립트를 실행하고, 결과가 바뀌면 자동으로 커밋·푸시합니다.
3. `assets/js/news-feed.js` — 페이지가 열릴 때 `data/news.json`을 fetch해서 기존 목업 카드를 실제 기사로 교체합니다. fetch에 실패하면(아래 "배포/로컬 테스트" 참고) 원래 목업이 그대로 보입니다.

## 설정할 것 — 사실상 없음

키 발급/Secrets 등록 단계가 없습니다. 레포를 GitHub Pages로 배포하기만 하면 다음 스케줄부터 자동으로 작동합니다. 바로 확인하고 싶으면 Actions 탭 → "Fetch news (아침/점심/저녁)" → **Run workflow**로 수동 실행할 수 있습니다.

## GitHub Pages로 배포 (중요)

`assets/js/news-feed.js`는 브라우저 `fetch()`로 `data/news.json`을 읽습니다. **파일을 그냥 더블클릭해서 `file://`로 열면 브라우저 보안 정책 때문에 fetch가 항상 실패**하고 기존 목업만 보입니다 (에러 없이 조용히 무시되도록 만들어 뒀습니다).

실시간 뉴스가 실제로 보이려면 http(s)로 서빙해야 합니다:

- **배포**: 레포 Settings → Pages → Branch를 `main`으로 설정하면 `https://<사용자명>.github.io/<레포명>/`으로 서빙됩니다.
- **로컬 테스트**: 프로젝트 폴더에서 `npx serve` (또는 VSCode의 Live Server 확장) 실행 후 `http://localhost:...`로 접속하면 됩니다.

## 참고 / 한계

- 완전 무료지만 호출량 제한이 명시돼 있진 않습니다 — 다만 하루 3회 × 카테고리 6개 = 18회 정도라 문제될 수준이 아닙니다.
- 구글 뉴스 RSS는 네이버와 달리 실제 기사 요약문을 안 줍니다. 그래서 카드의 설명 텍스트는 "OO일보 보도"처럼 언론사명 기반 문구로 대체했습니다.
- 기사 링크는 구글 뉴스 리다이렉트 주소(`news.google.com/rss/articles/...`)입니다. 클릭하면 실제 언론사 원문으로 정상적으로 넘어가지만, 링크 자체가 언론사 도메인은 아닙니다.
- 검색 결과가 네이버 뉴스와는 다른(네이버가 아니라 구글이 수집한) 국내 언론사 기사 위주입니다.
- `data/news.json`은 초기에는 빈 배열(`articles: []`)입니다 — Actions가 처음 한 번 성공적으로 돌고 나면 채워집니다.

## (참고) 나중에 네이버 API로 바꾸고 싶다면
